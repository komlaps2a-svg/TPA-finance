Buku Panduan & Rules

1. Manajemen SPP: Data tersimpan multi-bulan. Centang bulan yang telah dibayar. Wali santri hanya bisa melihat (Read-Only).

2. Sistem Absensi Otomatis:
- Absensi dicatat harian.
- Setiap MINGGU pukul 00:00, database absensi akan direset otomatis untuk menghemat kapasitas.
- Aplikasi akan mengingatkan admin untuk Export CSV setiap hari Sabtu.

3. Mode Transparansi: Wali Santri wajib memasukkan nama anak dengan benar untuk masuk. Mereka tidak dapat mengedit/menghapus transaksi apa pun.

4. Dana Darurat: Hanya gunakan untuk kondisi terdesak di luar Rencana Anggaran (RAB).
